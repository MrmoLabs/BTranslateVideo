# 尼尔：机械纪元中文语音 MOD

从主菜单打开「游戏音频汉化」，创建 Steam 版《尼尔：机械纪元》项目。填写含 `NieRAutomata.exe` 的安装目录，并选择 MOD 覆盖日语或英语语音档。安装后在游戏中切换到所选语音档即可听到被替换的条目。项目和导出文件保存在本机 `game_projects/`，扫描与打包只读访问游戏安装目录。

MOD 只写入已采用中文的 WEM。标为「保留原版」的台词会继续使用项目所选语音档，包括与中文台词共享语音包的原声条目。独立的背景音乐、环境音和音效仍由游戏引擎播放。带背景的候选可以分别试听中文干声、分离背景和回混成品，最终在游戏场景里验收。

## 本地工具

- 原声试听需要 [vgmstream CLI](https://github.com/vgmstream/vgmstream/releases)。将 Windows 发行包完整解压到 `runtime/game-audio-tools/vgmstream/`，或通过 `BTRANSLATE_VGMSTREAM` 指定 CLI 路径。
- 打包需要 [Wwise 2014.1.6 Authoring](https://github.com/ArthurHeitmann/F-SERVO/releases/tag/wwise_2014_1_6) 和 [nier_cli 的默认语音转换模板](https://github.com/ArthurHeitmann/nier_cli)。程序会尝试发现已安装的旧版 Wwise。也可通过 `BTRANSLATE_WWISE_CLI` 指定 `WwiseCLI.exe`，并把 `bin/assets/wavToWemTemplate_default.zip` 保存到 `runtime/game-audio-tools/wav-to-wem-template.zip`，或通过 `BTRANSLATE_WWISE_TEMPLATE` 指定模板位置。
- ASR、翻译和 TTS 使用应用的模型设置。使用参考音型 TTS 时，在音色库准备中文音色，并按句或按批选择。语音识别和翻译分别只补齐当前所选语言的空白原文和空白配音稿。

## 台词与翻译

扫描只建立音频索引，台词表初始显示“待识别”。准备本地映射后，「导入游戏台词」会按 Wwise 媒体 ID 补齐空白的日文原文、英文对照、中文配音稿和角色名。中文来自游戏文本，繁体可转为简体，仍建议对照原声校对。未匹配的条目可识别或手工录入。

「口语化配音稿」可在单句调试中使用，也可从台词表勾选多句后执行。用「有口语建议」筛选结果，试听原声并核对措辞，再点「填入配音稿」进入编辑。保存后可生成新的试听候选。

由本地输入生成 `app/game-data/nier-dialogue.json`，步骤见[台词映射说明](../app/game-data/README.md)。含游戏对白的生成文件留在本地。

## 角色音色

导入台词后，角色名会写入每条语音。在「角色音色」面板中为每个角色选择音色，例如 2B、9S、Pod 042 分别使用不同音色。生成时按以下顺序自动取音色：

1. 单句调试里为该句显式选择的音色；
2. 该句角色在「角色音色」中绑定的音色；
3. 台词表上方的「本批默认音色」。

「按名称自动匹配」会把角色名与音色名称/说明做规范化比较，例如 `Pod 042` 可匹配名为 `Pod042` 的音色；匹配不到时手动选择。修改角色音色后，已生成的候选不会被改写，新生成、单条生成和批量生成才使用新映射；保存后建议重新生成受影响角色的候选。

可以先用台词表的「试听」核对原声，再勾选同一角色的几条清晰对白，将「执行操作」设为「从勾选原声提取音色」。新参考音会以「角色名（选段 台词编号）」加入音色库。在「角色音色」里选中它并试听，再点「保存角色音色」即可使用。自动提取会跳过已知的音效占位文本。

批量生成时勾选「统一使用本批音色和情绪」，即可让本次所选台词使用同一个参考音和情绪，覆盖本次合成的单句音色、角色绑定和单句情绪。要比较普通话和游戏原声的效果，可选普通话参考音与「沿用参考音」，生成后在候选列表按音色和情绪试听。

从日语原声提取的音色可能把日语的语调也带进中文合成。「跟随本句原声」还会将本句原声用作情绪参考。要试听自然普通话，可先在「单句调试」选一段中文参考音，按角色选择「平静」等情绪，再比较新旧候选。

## 编辑和发布

1. 从台词表打开一条语音，查听日语原声。若发现跨语言对应候选，可试听英语以确认。按语音包、手工填写的场景与角色筛选台词。
2. 填写场景名和场景顺序，保存中文配音稿、音色及调试参数，再单条或批量生成。生成路线可选「跟随项目」「直接合成」「普通话表演 + Seed-VC」或「Drama 3」。Seed-VC 需要角色绑定目标音色，导入该句中文引导音时会优先用这段表演，否则从中文参考音合成。换路线会产生新的候选。`目标时长` 为 0 时使用原声长度，IndexTTS 2.5 超出预算时会额外尝试一次轻微提速，并选择比较接近预算的结果。仍过长的候选会提示复核。

   独立对白使用干声方式替换。混有背景的单声道或双声道条目可切换 HTDemucs 和 BandIt v2 生成不同候选。5.1 条目将中文放入中置声道，回听时检查其他声道里是否仍有原语。遇到原音效和原语无法分开的情况，可直接保留整个原版资源。
3. 决定每句采用中文、保留原版或待决定。选择场景后点击「连续试听」，按当前选择或全程原版回听。顺序为 0 的台词排在已编排的台词之后。浏览器按条目连续播放，实际触发和接话间隔在游戏里复核。
   单句栏共享一个播放器。点击候选即可播放，点波形会从指定位置播放，键盘也可用方向键、Home 和 End 定位。删除已采用的候选时，该句会回到待决定。在「配音设置 → 中文引导音」点击「录制引导音」，可选麦克风录制 0.2 至 29 秒的普通话表演，停止后试听，再用作本句引导音。
4. 勾选测试范围，执行「生成测试 MOD」，在发布预览确认替换和保留的条目。预览会显示共用资源的关联事件。用 [F-SERVO 或 Music Mod Manager](https://github.com/ArthurHeitmann/F-SERVO/wiki/WAI-WSP-Modding) 试装 ZIP 并确认对应的游戏触发点、语音完整度和相邻台词。
5. 回到工作台填写触发位置、标记候选实机通过，再导出正式 MOD。新候选超过目标窗口 0.15 秒时会在正式发布预览中报出。ZIP 包含中文 WEM、管理器元数据、游戏构建标记与替换清单。使用管理器卸载测试版本或切换版本。

首版扫描 `.wsp` 流式语音和 `.bnk` 内嵌语音。打包适用于与当前游戏索引匹配、可唯一定位的流式 Vorbis 条目。带内嵌预加载数据的语音、纯 `.bnk` 内嵌语音和 `.usm` 过场需要另行适配。日英对照基于同名语音库中的声音对象匹配；台词可由「导入游戏台词」按媒体 ID 自动补齐，未覆盖的条目和场景归属仍需人工确认。

## 发音规则

发音词典默认配置 `2B = two b`。工作台保留原稿里的 `2B`，合成时才使用英文读法。可以按同一格式添加其他关键词，例如 `9S = nine s`。规则按完整关键词匹配，`12B` 不会被 `2B` 的规则改写。修改词典之后，受影响的候选需要重新生成、采用和验收。

## BandIt v2 对照环境

BandIt 使用已有的背景分离 Python 环境，在独立的离线工作进程里推理。将 [bandit-infer 源码](https://github.com/openmirlab/bandit-infer/tree/96ea0ec12aeb444f379c2f5145fb8ee58b58cf19) 放在 `runtime/bandit-infer-source/`，将 [官方多语种权重](https://zenodo.org/records/12701995) 的 `checkpoint-multi.ckpt` 放在 `models/bandit-v2/`。工作进程在加载前校验 SHA-256 `abcfccf65446752a057f4a302c941479a54b7560ebf8d7bca039d2ea98e64cfc`。刷新工作台后，可针对不超过 120 秒的单声道和双声道混合条目切换 BandIt v2，和 HTDemucs 对照试听。

## Drama 3 本地推理

1. 解压 [audio.cpp v0.9.6 Windows Vulkan 发行包](https://github.com/0xShug0/audio.cpp/releases/tag/v0.9.6) 到 `runtime/drama3/`，保留可执行文件旁的 DLL 和资源目录。该发行包的 SHA-256 为 `94c6e1df6d98176eb5f0e3ad6c16e419f548bce3c65ccd8da97abf4c3966a7aa`。
2. 将 [Q2_K V2 权重](https://huggingface.co/Jmica/Drama-3-GGUF/blob/060acc8e5d9e5d16baf647c775dfe1a1438f5f35/drama-3-backbone-8bit-experts-Q2_K.gguf) 放入同一目录。文件大小为 17,053,647,360 字节，SHA-256 为 `5cb86588eff6404f4482830cfd3d69713f27115c02530a29f772535262fb7826`。使用参考音时，请遵守 [Fish Audio Community License](https://huggingface.co/Jmica/Drama-3-GGUF/blob/060acc8e5d9e5d16baf647c775dfe1a1438f5f35/LICENSE)。
3. 在单句或批量生成路线中选「Drama 3」。它沿用单句、角色和批量音色的优先级。选择「跟随本句原声」会用该句原声同时提供音色和表演参考。可以填写参考音实际说出的原文，按需要使用工作台原文或本地 faster-whisper 自动识别。
4. 在单句配音设置中填写「Drama 3 表演指示」，例如「低声、克制地说」。每个新候选可独立试听、采用和删除，背景混音、时长检查和保留整句原声仍由工作台处理。

如果日语参考音让中文配音带出口音，选择「Drama 3 普通话 + Seed-VC」。将具备普通话发音的参考音选为单句或本批音色，在「角色音色」里绑定角色原声。Drama 3 用普通话参考音生成表演，Seed-VC 再将它转换成角色音色。候选保留「变声前」轨道，可定位口音或音质变化是在哪一步产生的。

Drama 3 直出时，「跟随本句原声」优先使用该句原声，批量默认音色会被这一选项覆盖。日语参考音配中文稿时，工作台会在送入模型前加上普通话指示。安装了本地 faster-whisper 模型时，会用 CPU 核对新生成的音频，并拦截识别为日语的结果。同一批其余合格台词仍可保存候选。

工作台默认选择「跟随保温模型」。Drama 3 保温期间会优先使用 Drama 3 直出，空闲释放后回到项目路线。每批先准备好参考音，再复用同一个 Drama 3 会话逐句生成。用 Seed-VC 或 GPU 背景分离时会先释放 Drama 3。可在「设置 → 模型与工具 → 配音模型」调整 Drama 3 空闲保温时间，默认 90 秒，设为 0 时在配音任务结束后释放。

默认推理配置为 Vulkan、8 个专家层放在 CPU 和 2048 上下文。其他安装位置或硬件可以通过 `settings.local.json` 的 `drama3_executable`、`drama3_model`、`drama3_backend` 和 `drama3_cpu_expert_layers` 调整。详细设置见 [audio.cpp 的 Drama 3 文档](https://github.com/0xShug0/audio.cpp/blob/v0.9.6/docs/models/fish_drama3.md)。
