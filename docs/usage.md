# 使用指南

左侧主菜单分为 **项目、小说有声书、音色库、设置**。项目页集中提供搜索、导入创建、打开、重命名和删除；删除会移入可恢复的回收站，素材与结果仍保留在本机，不会释放磁盘空间。处理中项目不能重命名或删除。

打开项目后按 **素材与识别 → 翻译与校对 → 角色与配音 → 混音与导出** 四步进行，也可点击“一键完成”复用已有结果继续译制。译制目标语言在“翻译与校对”页设置；“角色与配音”显示当前语言并提供返回入口。背景音与音量归到“混音与导出”。详见 [工作流与存储设计](workflow.md)。

- **翻译与校对**：原文与译文逐行对照、直接编辑，支持全文搜索、待翻译筛选，以及每页 20 / 50 / 100 句。表格随页面自然滚动，校对保存按钮始终可见；“详情”在浮层中提供起止时间、角色和原片预览。“细调 / 试听”直接打开当前句的声音浮层。
- **角色与配音**：表格中同时修改多句台词、角色和情绪，也可勾选后批量设置。宽窗口按列展示，普通窗口把角色、情绪与强度排到台词下方，优先保证台词编辑宽度。表格没有独立纵向滚动条；点击“细调 / 试听”会在当前页面上打开浮层，生成结果显示在浮层内，关闭后保留表格滚动位置。试听使用当前草稿，不替换已保存字幕或成片；整片配音仍需保存设置。
- **混音与导出**：播放含背景音的译制 MP4，勾选“显示译文字幕”切换字幕。也可下载原画质双音轨 MKV、音频与字幕。
- **音色库**：独立维护参考声音，并在不同项目的角色中选用。修改预设不会自动改变已绑定项目的声音。
- **设置**：独立页面提供“常用参数”和“模型与工具”两个分组。切换菜单会保留设置草稿，保存后用于之后启动的任务；也可明确放弃设置修改。

切换主菜单会保留当前项目的字幕与声音草稿；打开另一个项目时可选择保存、放弃或继续编辑。刷新或关闭页面时，未保存的项目、音色预设和设置修改会触发离开提示。

### 逐句情绪

默认“沿用参考音”，延续原来的配音方式和语音缓存。可以手动选择开心、愤怒、悲伤、害怕、厌恶、低落、惊讶、平静，并设置轻度、中度或较强。课程建议先用轻度；动漫对白可逐句试听后增加强度。音色仍来自对应角色的参考声音。旧项目没有情绪字段时无需迁移。

本阶段使用本地 IndexTTS 情绪向量，不自动判断原片每句情绪。预设只表达方向，实际听感、自然度及音色保持程度需要试听确认。情绪与强度进入语音缓存标识，改变表达只重新合成受影响的片段；相同角色、情绪与强度才合批。试听与整片共享原始语音缓存，合适的试听结果可以直接复用；整片仍按既有规则对齐，短配音保持原速。

## 使用流程

1. **导入视频**：选择文件或填写完整本地路径，选择源语言、课程/动漫。导入时保存一份视频副本。
2. **原文字幕**：运行识别，使用词级时间戳和本地模型恢复完整句意后再分段，或者导入 UTF-8 SRT。模型首次加载需要时间，诊断日志可查看进展。旧项目可点击“重新断句”；成功替换前自动备份字幕、译文和成片到项目 `history/`，随后需要重新翻译、配音和导出。
3. **中文翻译**：在设置里填入术语表，运行“翻译缺失段落”。默认结合相邻原文、角色和视频标题翻译，复杂语序、否定、条件和长句增加一轮本地语义审校。可以直接编辑原文、中文、起止秒数和角色编号，点击“保存校对”。
4. **参考声音**：单角色可从原片自动提取；多人视频可在“角色与配音”运行自动区分说话人、试听并采用分配；也可手动新增、改名、删除角色，按角色筛选并批量指定台词。为每个角色选用音色库或上传独立的干净录音。接受 3～30 秒，建议 5～15 秒。
5. **配音试听**：生成中文配音。修改一句译文只重新合成受影响的片段；重复的同文同角色语音只合成一次。对齐会预先规划全片时间，在默认最多提前 0.75 秒、延后 1 秒的范围内利用相邻时间，避免新增配音重叠和逐段累积漂移；变速参数仍不超过所设上限。真正无法完整容纳时指出段号，不截断句尾。原始重叠对白保留原有混音关系。

   配音短于可用窗口时保持自然原速，剩余时间留白，成片背景音照常播放，不拉长配音来填满字幕。格式不一致时只重采样，不经过变速滤镜；只有配音过长才在最大倍速内加速。旧对齐缓存会核对原始语音时长，短配音被拉长或截短的缓存不会复用。旧成片需要重新生成配音与导出以应用此规则，原始语音缓存可继续复用。
6. **背景声音**：新项目默认保留原片背景音，使用本地 HTDemucs 分离原对白，再混入中文配音。背景音量默认为 1；也可选择仅中文配音或上传独立背景音。旧项目保持原来的声音模式。修改声音设置后重新导出即可，已有中文配音继续复用。
7. **导出与观看**：导出后在“混音与导出”页直接播放中文成片，可拖动进度、全屏、开关中文字幕。页面版使用 H.264/AAC MP4，最高 720p，不放大原画面；下载的 MKV 保留原画质、原音轨，增加默认中文音轨和双语字幕。另提供 MP4、含背景中文 FLAC、纯中文 WAV 及 SRT。旧成片可单独“更新页面预览”，无需重做配音。

断句模型的文本仅用于建议边界；程序按原始词对齐并保留重复词，无法可靠对齐时自动尝试只返回词编号的协议。长代码操作静音会单独处理，不计作连续讲话超长。长视频重试会复用已验证的断句缓存；失败输出留在项目 `cache/segmentation-attempts/`，已有字幕在整阶段验证成功前不会替换。错误的半句边界会合并回相邻原文。36 秒是分句目标：超长复句优先按明确的独立分句拆开，没有可靠边界时保留完整句意；实际配音仍逐段检查时间对齐，不裁掉句尾。

“一键完成”串行执行各阶段。已有原文、非空译文及内容一致的语音片段会复用。保存原文修改但没有同步修改中文时，对应旧译文会清空，防止把旧译文当成新内容。翻译按钮只补齐空缺，保留人工校对结果。

### 优化已有译文

在“翻译与校对”点击“优化已有译文”，程序先依据原文独立翻译，再审校语义，生成逐段对比。原译文、已有配音和成片在生成建议期间保持可用，失败或取消可重试并复用已完成的缓存。“查看逐句对比”显示原文、前后译文与粗略朗读时长，可以全选或逐段勾选，最后“应用所选优化”。人工校对未保存时禁止应用；字幕版本变化后旧建议失效，避免覆盖新校对。

应用后点击“一键完成”，已有原文和中文继续复用，仅重新合成改动的语音段并导出成片；原有成片会保存到项目 `history/`。只修改句尾标点或空白的建议会被过滤，减少无意义的配音重做。

设置中的“翻译语义审校”默认自动，也可选每段审校或关闭额外审校；“优化已有译文”始终执行审校。“朗读稿等义精简”默认只在估计超时后尝试压缩口头赘词，仍检查原文数字和问句是否保留，编号、时间、角色保持不变。估算不等于实际配音长度，最终仍按真实合成音频检查对齐，无法容纳时不会截掉句尾。

此流程通用于英语/日语课程及动漫上下文，不依赖某一视频的固定术语。模型仍可能误判指代、否定或省略内容；结构检查不能证明语义完全正确，建议逐句核对关键知识点和角色关系。

## 本地模型

| 阶段 | 默认模型/运行时 |
| --- | --- |
| 识别 | faster-whisper large-v3，CUDA FP16 |
| 翻译 | Qwen3-8B Q4_K_M GGUF，llama.cpp Vulkan |
| 配音 | IndexTTS-2.5，CUDA BF16 |
| 背景分离 | HTDemucs，CUDA，30 秒流式分块 |
| 音视频 | FFmpeg / FFprobe，预览优先 NVENC |

`models/faster-whisper-large-v3-turbo` 若已准备，也可在模型设置中选择，减少识别时间和资源占用。默认使用程序管理的本地翻译进程，翻译结束后退出释放显存；也可以连接自己已有的本机兼容服务，地址只接受 localhost / 127.0.0.1 / ::1。

音频对齐默认使用 4 个 CPU 任务并行，设置中的“音频处理并行数”可选 1～8；“允许配音延后”可设 0～3 秒，设为 0 表示不接受延后。已生成的语音和已完成的对齐缓存会复用，原文、译文和字幕时间不因对齐而改写。

IndexTTS-2.5 默认使用同一模型的自适应文本批处理，最多 4 段；设置中保留双段和单段兼容模式。待生成片段按参考声音和长度分组，输出仍按原字幕编号和时间轴放回；新角色先合成一段完成参考声音预热，其余片段立即参与合批。显存余量不足时降低批量，批处理异常按 4→2→1 重试，需要分句的文本单独合成，不让一条不适合合批的文本关闭整项任务的批处理。声学解码和声码器仍逐段执行，GPU 模型仍按阶段独占使用。

“配音”页显示最近一次运行的实际批量、最大批量、新生成/复用数量、显存或文本回退原因，以及模型加载、语音生成、声学生成、声码器等耗时。模型加载与参考音准备仍需要时间，配音模型可限时保温复用；合成累计时间包含参考音处理、文本准备和文件读写。

## 项目文件

- `app/`：本地服务、任务队列、识别/翻译/配音流程与中文界面。
- `scripts/`：模型准备和独立模型工作进程。
- `projects/<项目编号>/`：视频副本、字幕、参考声音、语音缓存、导出文件、处理日志及 `project.json`。
- `models/`：模型权重；`vendor/index-tts/`：官方配音代码和独立环境。
- `runtime/`：下载缓存、llama.cpp、验收资料。
- `Data/`：用户输入素材，不作为程序依赖，不修改原文件。

项目正文保存在 `project.json`，高频任务快照保存在 `project-state.json`，网页轮询也按正文版本分开。复制项目时应保留整个文件夹。“存储管理”可统计、预览并清理明确范围，默认不删除任何文件。

配置与项目清单使用 UTF-8 无 BOM，更新采用临时文件与原子替换。运行中不允许修改当前项目，浏览器会提示未保存编辑；中断状态在下次启动时恢复为可重试状态。配音和输出按字幕、参考声音及模型信息检查，避免错误复用。

## 当前边界

- 语音识别负责内容；Community-1 负责区分谁在什么时候讲话，不识别人名或身份。自动分组后仍需听原声核对，重叠对白允许保留并混音。
- 不改变人物口型；不自动擦除画面中的原字幕。
- 背景分离是估计，无法保证原背景逐样本不变；歌声、复杂音效或重叠对白可能残留或损失。有独立背景音轨时，上传自定义背景可避免模型分离误差。原音轨仍完整保留在 MKV 内。
- 英日识别、术语翻译、情绪和音色仍可能有误。保留原音轨和原文字幕便于核对。
- 原视频的 HEVC 等编码可能无法在浏览器预览；导出页会单独生成兼容 MP4，保留原画质的 MKV 可用支持多音轨的播放器观看。

## 连续试听与界面语言

配音页顶部显示模型是否加载、是否正在合成及剩余保温时间。连续调试不同句子和情绪时不必重新加载模型；首次启动、空闲到期、模型变化或切换其他 GPU 阶段后仍需加载。设置中可调整保温 0～60 分钟，默认 10 分钟；随时可手动释放显存。当前任务运行/排队时释放按钮会暂时禁用。

顶部“界面语言”可切换中英文，不修改用户字幕或项目名称，也不提交/放弃草稿。导入时支持 12 种源语言及自动检测，译制目标可选择中文、英语、日语、西班牙语或阿拉伯语。浏览器原生音视频控件的语言由浏览器决定。

## 音色库与项目角色

左侧“项目”和“音色库”是两个独立菜单。切换菜单会保留当前项目的字幕、情绪和声音草稿。

在音色库点击“新建音色”，填写名称和说明，上传 3～30 秒参考声音；推荐使用 5～15 秒清晰、少背景音的录音。可预听、修改和归档音色，已归档音色可恢复。项目内已有参考声音也可通过“存入音色库”保存成预设。

在项目的“角色与配音”页展开“项目角色与音色”，为角色选择预设并点击“应用音色”。项目保存一份独立参考声音副本：后续修改或归档预设不会改变该项目的声音。需要采用更新后的预设时，再次应用即可。更换项目音色后，需要重新生成相关配音和成片，原有字幕不变。

音色库保存在本机 `voices/`，不随源码发布。音色预设是参考录音与名称说明，不需要为每个角色训练模型。

## 多句配音工作台

配音页可同时编辑多句中文稿、角色、情绪及强度，支持搜索台词、筛选角色和每页 20/50/100 句。勾选句子后可批量设置角色、情绪或强度；“本页全选”只选择当前筛选页，已勾选的句子跨页保留。切换项目时清空选择，避免把另一项目的句子编号误认为已选。

批量设置只更新页面草稿，点击“保存配音设置”后用于整片配音。沿用参考音时不单独指定强度。每行“细调 / 试听”可打开原速单句试听，原有情绪和模型保温机制继续生效。

## 查看处理记录

点击页面右下角“处理记录与诊断日志”，可在大面板切换运行记录和诊断日志，搜索当前显示内容，筛选错误或警告。开启“自动跟随最新”持续查看处理进度；阅读旧记录时取消勾选即可暂停刷新。

运行记录保留最近 200 条；诊断视图默认显示末尾 500 行，可增加到最多 3000 行。下载按钮会导出最近运行记录和完整进程日志。日志可能含本机路径和台词，分享前请自行检查。

## 设置布局

设置窗口分为“常用参数”和“模型与工具”两个页签。翻译、配音性能和时间对齐集中展示；模型路径按识别、翻译、配音及媒体工具分组。页签切换保留当前输入，底部保存按钮会提交两个页签的全部参数；取消则保留原配置。

## 选择译制目标语言

导入视频时分别选择原语言和译制目标语言。已有项目可在标题下方选择目标并点击“切换目标语言”；确认后，先备份旧译文、试听、字幕和输出，再清空当前译文。原文、时间轴、角色、音色及背景设置保留，随后重新翻译和配音。

IndexTTS-2.5 支持中、英、日、西、阿五种目标语言；IndexTTS-2 仅支持中英。其他源语言仍可识别并翻译到上述目标。英语、西班牙语、日语和阿拉伯语配音暂用模型原生逐句合成路径，继续复用保温模型；中文保留原有自适应批处理。

旧项目省略目标字段时按中文处理，原中文语音缓存保持兼容。其他目标的字幕为 `translated.srt` / `translated.vtt`、人声音轨为 `translated.wav`。音视频和字幕轨的语言标签随目标更新。跨语言音色克隆不保证完全消除口音，需试听确认。

## 直接录音创建音色

在“音色库 → 新建音色”中选择上传文件、话筒录制或系统录制。Windows 本机录音可以选择输入话筒或输出扬声器／耳机；系统录制只采集所选输出设备的声音，不采集画面，也不需要浏览器共享屏幕。仅按下“开始录音”才采集，最多 29 秒，停止后先试听，再保存音色。参考音仍需 3～30 秒，建议 5～15 秒清晰独白。录音结束不自动加入音色库，取消或关闭弹窗会停止本次录音。

Windows 需要允许桌面应用使用麦克风；输入无声、设备拔出、权限拒绝都会在录音区域显示错误。系统录制时应先确认所选输出设备正在播放希望使用的参考内容。设备列表的可用性不等于实际录音听感验收。其他平台保留上传文件入口。

## 小说与有声书

1. 进入“小说有声书”，新建书籍，再新建章节。每章可粘贴最多 250000 字正文。
2. 选择章节默认音色和朗读语言。正文直接转语音，不经过翻译；目前沿用 IndexTTS 对中文、英语、日语、西班牙语和阿拉伯语的语言支持。
3. 点击“自动分句”预览，也可直接保存，由程序先分句。分句按段落、句末标点和长度拆分，保留原有词句、引号、数字；长句过长时按停顿或长度继续分块，不由语言模型改写正文。
4. 在逐句朗读稿中编辑文字，或为某句覆盖音色与情绪。重新分句时，相同文字保留对应设置；修改正文并保存前会提示确认重新分句。
5. 保存后生成本章、全书或单句。进度显示排队、准备音色、加载／复用模型、生成句子和合并阶段。小说与视频共用任务队列和保温模型，避免同时重复加载两套配音模型。
6. 完成句子会即时保存。取消、关闭服务或失败后再次生成，已验证的语音缓存继续复用；修改一句只重新合成受影响内容。软件重启将未完成任务标记为中断，由用户决定继续。
7. 章节句子全部完成后，自动生成 WAV 和 MP3。所有章节完成后，可按章节顺序“合并导出全书”，选择 WAV 或 MP3。句间停顿可设 0～3 秒；全书章节之间留 1 秒停顿。整个过程保持自然语速，不为视频字幕窗口变速。

切换菜单保留章节草稿，切换章节／书籍时提示保存或放弃。已有音频显示的是已生成版本；修改正文后需要保存并重新生成。归档书籍保留正文、音色设置与音频，可在已归档列表恢复。小说目录 `audiobooks/` 和临时录音 `runtime/recordings/` 均不进入 Git。

## 查看处理进度

视频和小说处理时会显示当前阶段、真实完成数量、耗时、复用片段和阶段记录。顶部“任务进度”与右下角浮动提示可跨页面使用，并可直接查看任务日志、取消排队或正在运行的任务。无法测量的模型加载阶段显示等待状态；预计时间仅在样本足够时显示。详见[进度说明](progress.md)。


### 译文与配音语言

在“翻译与校对”或“角色与配音”中设置输出语言，两处设置同步。修改配音稿不会自动改变语言参数。已将日文稿手动改成中文时，选择“中文 → 保留已有译文 → 应用语言”，再重新生成试听。需要重新翻译时选择“清空译文，重新翻译”。切换会备份旧项目与输出，使旧试听、配音和成片失效；保留原文、时间轴和音色设置。

翻译请求使用批次内编号，参考上下文不占用输出编号。返回结果严格校验后映射回原字幕；错号时提供具体缺失、多余编号并重试，持续错号会缩小批次。系统不会按返回顺序猜测句子对应关系。


### 翻译中的数字核对

明确数值必须保持一致，支持“8 / 八”、全角数字和常见中文数字等值写法。校验未通过时，会按本批次编号反馈并缩小批次重试。审校或精简产生无效结果时，保留已经通过检查的译文，并标记“译文待核对”。服务连接失败和取消不会被当成正常回退。

对于日语词尾与带称呼的人名之间夹入的孤立数字，系统仅在无数量、日期等线索时标为疑似识别噪声。这是待核对提示，不是自动修正原文；原字幕保留不变。字幕页可点击“待核对 N 句”集中查看，并打开“详情”对照原片。修正文字后旧提示不再沿用。

### 单句重译与角色预配置

字幕行中的“重新翻译”会结合相邻上下文生成新版本。当前页面草稿先保存，原译文和成片在生成期间保留；对比后点击“采用新译文”，只替换这一句。修改过本句原文或译文的迟到结果不能覆盖新编辑。重新翻译会实际请求本机模型，不复用旧翻译缓存。

在“项目角色与音色”中点击“＋ 新增角色”，可以命名角色、预先上传参考音或绑定音色库，再在台词表或批量设置中分配角色。没有台词的角色也会保留。

“从原片取样”依据这个角色已经分配的台词选择 3～10 秒片段，允许连接短的相邻台词，并排除其他已标注角色的重叠区间。取样是可取消任务，成功后备份旧参考音并替换；失败或取消时旧音色不变。这不是自动识别多人身份。未分配台词、片段过短或混有其他说话人时，需要先校对分配，或上传更干净的参考音；原片音乐也可能保留，生成后请试听确认。

“生成本句试听”完成后会自动播放本次结果，包括命中缓存的试听。切换句子、关闭细调、切换菜单或隐藏页面会撤销自动播放意图。若浏览器拦截自动播放，使用播放器的播放按钮即可。

### 对照原声校对

字幕行可直接点击“听原声”；“译文待核对”提示展开后也有“听这一段原声”。播放器只播放这句对应的原片音轨，支持重播、循环、播放速度，以及前后各 2 秒的上下文。它不生成配音、不调用模型，也不保存或覆盖正在编辑的字幕。字幕详情内的“听本句原声”使用当前草稿起止时间，无需先保存。

原片只按所选时间转换为兼容浏览器的 WAV，视频编码不受浏览器支持时仍可听原声；结束时自动停止，启用循环则重复本段。播放器显示句子编号和原片时间；切换项目、菜单、步骤或关闭详情后停止播放。片段缓存保存在本机项目 cache 中，不加入发布内容。

## 单句配音视频预演

在“配音与情绪 → 细调 / 试听”中，选择一句并调整配音稿、角色或情绪，然后点击“生成本句视频预览”。它使用当前草稿生成配音，配上该句对应的原片画面，完成后自动播放；浮层内可重播、拖动播放进度，以及勾选字幕。不会保存草稿、覆盖字幕或重新导出整片。关闭浮层、切换句子或离开页面会停止播放；修改草稿或时间后，旧预览会标为之前版本。

预演仅播放选中句的译制人声，原对白静音；背景音仍在成片阶段合成，不代表含背景音的最终混音。短配音保持原速、后面留白；长配音仅在所设提前/延后及倍速上限内利用相邻空白，无法完整容纳时提示修改，绝不截尾。整片生成时会结合所有相邻配音重新规划时间，最终对齐以成片为准。单句原始语音缓存与试听、整片配音共享；仅调整时间时不重新合成声音。

单句视频最长 5 分钟，输出为最多 720p 的 H.264/AAC MP4，字幕可开关。所有预览和缓存仅保存在本机项目目录；失败或取消保留之前成功的试听与成片。

## 自动区分说话人

“配音与情绪 → 自动区分说话人”可使用本地 Community-1 识别角色。设置设备和人数，识别后试听候选音色、听原声核对分配，再采用勾选句子。多人、静音和重叠句默认不勾选，不会自行改写字幕；旧角色和音色保留。模型需额外准备，详见[本地说话人识别](diarization.md)。


### 翻译失败后的人工处理

自动翻译和批量审校遇到单句数字、编号或模型输出格式错误时，会先重试并缩小批次；仍失败的句子保留原文和已有译文，标为“译文待核对”，继续处理其他句子。错误结果不会填入译文或用于配音。进度分别显示已处理、通过、跳过数量，详细原因保存在项目记录中。

在“翻译与校对”中点击“待核对”数量或选择“译文待核对”，展开提示后可听原声、手动修改或重新翻译。保存修改后该条旧提示失效；重新执行翻译只处理仍为空的句子。一键流程会完成其余翻译，但在缺少译文时等待人工补齐，不自动生成缺句的配音和成片。连接失败、HTTP 服务错误、模型加载失败与用户取消仍会停止任务。


### 单句重新识别与双语润色

字幕校对中，原文下方提供“重新识别原文”和“润色原文”，译文下方提供“润色译文”和“联合校对”。这些操作先保存当前草稿，再在主表格内显示本句候选；核对后点击“采用本句”才会替换，也可勾选后批量采用，其他句子、时间轴与角色不变。

- **重新识别原文**：使用当前识别模型重新处理这句的原声音频。前后最多各 2 秒用于辅助识别，仅保留词时间中心落在本句范围内的内容。没有语音或时间戳时保留现有内容并提示调整范围。
- **润色原文**：根据邻句上下文修正识别错字、断词、标点及赘词。这是文字推断，不代表已验证音频；尤其是人名与数字，应点击候选窗口的“听这一段原声”核实。
- **润色译文**：对照现有原文修复误译、外语残留和不自然的表达。
- **联合校对**：先提出原文修正，再基于修正后的原文生成译文，一次核对并采用这一对文本。文字模型报告原文不确定、改变数字，或译文持续校验失败时，会自动重新识别本句原声，再基于识别结果继续翻译。无需逐句另点“重新识别”。

单独采用改变后的原文会清空对应旧译文，请再“重新翻译”；联合校对会一起采用新原文和新译文。采用前会备份旧字幕和输出，并使旧配音、试听与成片失效。生成失败、取消或字幕已被修改时，旧内容保持不变。

中文目标会检查日文假名残留，包括昵称、敬称和半角假名。失败时先要求模型重试，仍失败则按单句跳过、标为待核对；不会将失败结果写入译文。已有项目的残留也会显示在“译文待核对”筛选中，可逐句重新翻译或润色。英文代码名、库名和公式可保留。仅由汉字组成的日语无法靠假名检查可靠区分，仍需人工核对；人名音译也需听音确认。


### 批量字幕工作台

字幕表格可跨页勾选，也可点击“选中全部筛选结果”“选中全部待核对”。选择润色译文、重新翻译、润色原文、联合校对或重新识别原文后，点击“处理所选 N 句”。候选、修改原因及失败信息直接出现在对应单元格内，无需逐句打开窗口；表格随整页滚动。

候选可以直接编辑。核对后点击“采用所选候选 N 句”，一次采用所有已勾选且生成成功的候选；也可在行内采用本句。失败句不会混入采用范围，可筛选“本轮处理失败”，使用“重试失败 / 继续未完成”继续处理。中途取消保留已完成候选；采用一部分后，其他未修改句子的候选仍可继续采用。所选范围、候选编辑草稿保存在本机浏览器中，翻页、切菜单及刷新后可恢复。

批量文字处理共用一次本地翻译模型会话；原声重新识别由同一个 Whisper 实例逐条处理片段，避免每句重新加载模型。句子仍独立记录结果，失败不会覆盖现有字幕。网络、模型加载等系统错误会停止本轮并保留已完成结果，修复后可续跑。单独采用变更后的原文会清空对应旧译文；联合校对可以一起采用新原文和新译文。采用前备份旧结果；原文、译文、时间、角色或目标语言冲突时拒绝覆盖。


### 联合校对的自动修复

校验失败会把实际失败的候选与具体原因交给本地模型修正。中文“两三年”“两三次”等范围仅在原文明示相应两个数值和单位时视为等值；“三格”“三帧”“两丁目”也能正确校验，错误数值仍会被拒绝。残留日文片段经两次整句处理仍未解决时，最后一次尝试只转换残留片段，并重新校验完整译文，避免反复输出同样的假名。

联合校对遇到原文疑点、数字修复或持续的内容校验失败，会将对应句子排入自动回听。文本模型先释放显存，Whisper 在同一个实例内处理这些片段，再统一加载文本模型继续翻译。界面显示等待回听或重新识别后的翻译状态；重新识别结果逐句持久保存，后续译文失败或取消后续跑可复用已有识别结果。每轮回听有界，不无限重试；无有效语音、接口或模型故障仍会留下明确原因。

自动回听使用所配置的本地识别后端，通常保留前后各最多 2 秒上下文，只采用词时间中心落入本句的内容。它会增加疑难句的处理时间，仍可能识别错人名或遗漏边界附近的语音；重新识别和音译说明随候选展示，不表示已核实人物身份。生成候选不会自动替换已保存原文、译文或输出；可在主表格中跨页批量采用。


批量校对中，如果勾选了尚未完成的句子，“重试所选未完成”只继续这些句子；没有勾选未完成项时，“重试全部未完成”继续所有失败或待处理句子。历史批次中混合的原声识别、原文润色和翻译任务会按每句原先选择的操作执行，已完成候选保留。遇到损坏的语音缓存，系统会将坏文件留作隔离备份并重新生成；有效缓存继续复用。


在“配音与情绪 → 项目角色与音色”中，每张卡片的名称旁都有“删除角色”。删除有台词的角色时，可保留台词为未分配，也可迁移到其他角色；最后一个角色同样可以删除。未分配状态保留原文、译文、时间和情绪，不作为实际角色显示。之后可新增角色，在表格筛选“未分配角色”，选中全部筛选结果后批量分配并保存；尚未分配的台词不能生成配音或本句试听。


## 在字幕校对页导出字幕

导入时可选择“仅识别字幕 / 翻译字幕 / 完整译制配音”，新项目默认仅识别。只需要方言字幕时选择“仅识别字幕”，识别后进入“校对与导出”，直接导出原文 SRT 或 TXT。项目头部可以切换目标，已有内容会保留；旧项目继续采用完整译制流程。

在“素材与识别 → 本项目识别设置”选择当前项目的识别器、原语言、设备与热词。全局使用 Fun-ASR 时，新导入默认中文。上次识别来源和下次识别设置分开显示；保存设置不会自动重做字幕。重新断句复用原识别缓存；要应用新模型或热词，请明确选择“重新识别原声”，现有结果会先备份。

“检查运行环境”只检查依赖与设备，不加载大模型。“试识别前 10 秒”会实际加载模型并识别短片段，首次加载可能较慢，可在任务进度查看阶段与取消；试识别不会替换项目字幕。

字幕输入会自动保留本浏览器的本地草稿，可用 Ctrl+S 保存到项目。刷新或重新打开项目时会提示恢复；其他窗口已保存新版本时，只允许导出旧草稿比较，避免覆盖。字幕表格默认提供回听、详情和“更多”；勾选句子后显示批量操作。时间轴保留小数秒，支持紧凑或舒适密度。

“更多 → 时间轴与拆合句”（也可从字幕详情打开）按需读取本句及前后各 2 秒原声的波形。点击或拖动波形、拖动定位滑块，或直接输入开始/结束/拆分时间；下拉框选择本次调整哪一条边界。波形只显示音量变化，不代表模型已经确认的文字边界。音频播放器可回听整段波形范围。

拆句需在原文框中点击设置文字光标，并指定对应的音频时间；已有译文时，还要分别选择译文光标位置。不会按字数自动切译文。与下一句合并要求两句角色和情绪一致，且都有译文或都没有译文。操作保留原句编号，为新句分配独立编号，不重排其他句子的编号；保存前保留为草稿，保存后备份已有输出并使旧配音/成片失效。

“撤销校对操作 / 重做校对操作”用于尚未保存的拆合句、时间调整和人工标记。保存、切换项目或另行输入文字后，清除这些操作的撤销记录，避免撤销覆盖后续输入。文字框的 Ctrl+Z 继续使用浏览器原生撤销。记录最多保留 20 步并限制在约 400 万字符的快照总量；超过容量时会提示不能保留本次撤销记录。

每句“更多”中可标记“未核对 / 已核对 / 存疑”；选中多句后可批量标记，并按这些状态筛选。标记随草稿保存，绑定当时的原文、译文、角色和毫秒时间轴；这些内容变化后自动失效。只修改人工标记不会清空配音、成片或语音缓存。

Ctrl+Enter 回听光标所在句；Alt+左右箭头回听当前筛选内的上一句/下一句。播放器也有上一句、下一句和“连续回听”；连续回听到筛选范围末尾后停止，与单句循环互斥。操作文字框时不会截获普通空格或 Ctrl+Z。

“翻译与校对”页的字幕表格上方直接提供“导出原文 SRT”和“导出译文 SRT”。导出使用全部句子的当前编辑稿，包含未保存修改，不受搜索、筛选或分页影响；不会自动保存、替换项目文件或使配音/成片失效。尚未采用的候选不在导出范围内。

原文文件名以 `.original.srt` 结尾；译文以当前生效目标语言代码命名（如 `.zh.srt`、`.ja.srt`）。空白译文跳过，保留其余句子的原时间并连续编号，页面提示跳过数量；没有译文时禁用译文导出。导出文件使用 UTF-8 无 BOM。原文为空或时间无效时提示对应句子，不生成错误字幕。


## 直接回听已生成的本句配音

“单句细调与试听”现在自动查找已生成音频，提供“播放已生成配音”和播放器。已有整片人声音轨时优先按 `dub_timing` 的实际对齐位置播放对应片段；没有整片结果但有匹配的逐句语音缓存时，直接播放原速人声。播放不加载 TTS、不保存草稿，也不重新生成音频。

修改台词、角色、情绪或声音设置后，已有旧音频仍可回听，但明确标为“之前版本”；新效果仍需点击生成。完成的音频会有独立逐句索引，保存修改或更换声音后仍可定位上次音频。旧项目也会尝试现有缓存、上一份字幕备份或单句试听记录。既没有音频也没有可验证缓存时，提示本句尚未生成，不会自动启动模型。

缓存回听不包含背景音或整片对齐；整片人声片段可能包含重叠角色。无对齐记录的旧项目优先播放完整逐句缓存，只有音轨可用时按字幕窗口截取，并标明边界限制。含背景音的完整效果仍在“混音与导出”观看。


## 整片对齐的常规与保底上限

默认启用自适应对齐。先使用常规上限（默认 1.35 倍、提前 0.75 秒、延后 1 秒）；无法容纳时，只收紧两端超过约 0.2 秒的近静音并保留起音前 100 ms、句尾后 120 ms，再尝试借用相邻空白，必要时逐步增加倍速。保底默认上限为 1.5 倍、提前 1.5 秒、延后 3 秒，均在设置中可见；短配音仍不慢放，不改写原文或译文，不裁掉语音结尾。原始语音缓存始终保留，处理写入派生文件。

不希望扩大常规范围时，在“设置 → 常用参数 → 配音与时间对齐”选择“严格使用常规上限”。整片配音页显示本轮实际采用的上限与处理数量，修改后旧报告会标为需要重新检查。

如果连保底范围也无法容纳，页面提供全部相关句子的冲突报告和“只看对齐问题”筛选，可直接批量校对并回听缓存。已生成语音不丢弃，重试只合成内容、角色或声音实际变化的片段。已有缓存已足以证明某段无法容纳时，会在生成剩余语音前预检报告；尚未生成音频的准确时长不能提前保证。
