# 使用指南

左侧主菜单分为 **项目、小说有声书、音色库、设置**。项目页集中提供搜索、导入创建、打开、重命名和删除；删除会移入可恢复的回收站，素材与结果仍保留在本机，不会释放磁盘空间。处理中项目不能重命名或删除。

打开项目后按 **视频导入 → 字幕校对 → 配音与情绪 → 成片与下载** 四步进行，也可点击“一键完成”复用已有结果继续译制。译制目标语言在“视频导入”页调整。

- **字幕校对**：原文与译文逐行对照、直接编辑，支持全文搜索、待翻译筛选，以及每页 20 / 50 / 100 句。表格随页面自然滚动，校对保存按钮始终可见；“详情”在浮层中提供起止时间、角色和原片预览。“细调 / 试听”直接打开当前句的声音浮层。
- **配音与情绪**：表格中同时修改多句台词、角色和情绪，也可勾选后批量设置。宽窗口按列展示，普通窗口把角色、情绪与强度排到台词下方，优先保证台词编辑宽度。表格没有独立纵向滚动条；点击“细调 / 试听”会在当前页面上打开浮层，生成结果显示在浮层内，关闭后保留表格滚动位置。试听使用当前草稿，不替换已保存字幕或成片；整片配音仍需保存设置。
- **成片与下载**：播放含背景音的译制 MP4，勾选“显示译文字幕”切换字幕。也可下载原画质双音轨 MKV、音频与字幕。
- **音色库**：独立维护参考声音，并在不同项目的角色中选用。修改预设不会自动改变已绑定项目的声音。
- **设置**：独立页面提供“常用参数”和“模型与工具”两个分组。切换菜单会保留设置草稿，保存后用于之后启动的任务；也可明确放弃设置修改。

切换主菜单会保留当前项目的字幕与声音草稿；打开另一个项目时可选择保存、放弃或继续编辑。刷新或关闭页面时，未保存的项目、音色预设和设置修改会触发离开提示。

### 逐句情绪

默认“沿用参考音”，延续原来的配音方式和语音缓存。可以手动选择开心、愤怒、悲伤、害怕、厌恶、低落、惊讶、平静，并设置轻度、中度或较强。课程建议先用轻度；动漫对白可逐句试听后增加强度。音色仍来自对应角色的参考声音。旧项目没有情绪字段时无需迁移。

本阶段使用本地 IndexTTS 情绪向量，不自动判断原片每句情绪。预设只表达方向，实际听感、自然度及音色保持程度需要试听确认。情绪与强度进入语音缓存标识，改变表达只重新合成受影响的片段；相同角色、情绪与强度才合批。试听与整片共享原始语音缓存，合适的试听结果可以直接复用；整片仍按既有规则对齐，短配音保持原速。

## 使用流程

1. **导入视频**：选择文件或填写完整本地路径，选择源语言、课程/动漫。导入时保存一份视频副本。
2. **原文字幕**：运行识别，使用词级时间戳和本地模型恢复完整句意后再分段，或者导入 UTF-8 SRT。模型首次加载需要时间，诊断日志可查看进展。旧项目可点击“重新断句”；成功替换前自动备份字幕、译文和成片到项目 `history/`，随后需要重新翻译、配音和导出。
3. **中文翻译**：在设置里填入术语表，运行“翻译缺失段落”。默认结合相邻原文、角色和视频标题翻译，复杂语序、否定、条件和长句增加一轮本地语义审校。可以直接编辑原文、中文、起止秒数和角色编号，点击“保存校对”。
4. **参考声音**：单角色可从原片自动提取；多人视频在字幕表中设置 `speaker_1`、`speaker_2` 等角色，并为每个角色上传独立的干净录音。接受 3～30 秒，建议 5～15 秒。
5. **配音试听**：生成中文配音。修改一句译文只重新合成受影响的片段；重复的同文同角色语音只合成一次。对齐会预先规划全片时间，在默认最多提前 0.75 秒、延后 1 秒的范围内利用相邻时间，避免新增配音重叠和逐段累积漂移；变速参数仍不超过所设上限。真正无法完整容纳时指出段号，不截断句尾。原始重叠对白保留原有混音关系。

   配音短于可用窗口时保持自然原速，剩余时间留白，成片背景音照常播放，不拉长配音来填满字幕。格式不一致时只重采样，不经过变速滤镜；只有配音过长才在最大倍速内加速。旧对齐缓存会核对原始语音时长，短配音被拉长或截短的缓存不会复用。旧成片需要重新生成配音与导出以应用此规则，原始语音缓存可继续复用。
6. **背景声音**：新项目默认保留原片背景音，使用本地 HTDemucs 分离原对白，再混入中文配音。背景音量默认为 1；也可选择仅中文配音或上传独立背景音。旧项目保持原来的声音模式。修改声音设置后重新导出即可，已有中文配音继续复用。
7. **导出与观看**：导出后在“成片与下载”页直接播放中文成片，可拖动进度、全屏、开关中文字幕。页面版使用 H.264/AAC MP4，最高 720p，不放大原画面；下载的 MKV 保留原画质、原音轨，增加默认中文音轨和双语字幕。另提供 MP4、含背景中文 FLAC、纯中文 WAV 及 SRT。旧成片可单独“更新页面预览”，无需重做配音。

断句模型的文本仅用于建议边界；程序按原始词对齐并保留重复词，无法可靠对齐时自动尝试只返回词编号的协议。长代码操作静音会单独处理，不计作连续讲话超长。长视频重试会复用已验证的断句缓存；失败输出留在项目 `cache/segmentation-attempts/`，已有字幕在整阶段验证成功前不会替换。错误的半句边界会合并回相邻原文。36 秒是分句目标：超长复句优先按明确的独立分句拆开，没有可靠边界时保留完整句意；实际配音仍逐段检查时间对齐，不裁掉句尾。

“一键完成”串行执行各阶段。已有原文、非空译文及内容一致的语音片段会复用。保存原文修改但没有同步修改中文时，对应旧译文会清空，防止把旧译文当成新内容。翻译按钮只补齐空缺，保留人工校对结果。

### 优化已有译文

在“字幕校对”点击“优化已有译文”，程序先依据原文独立翻译，再审校语义，生成逐段对比。原译文、已有配音和成片在生成建议期间保持可用，失败或取消可重试并复用已完成的缓存。“查看逐句对比”显示原文、前后译文与粗略朗读时长，可以全选或逐段勾选，最后“应用所选优化”。人工校对未保存时禁止应用；字幕版本变化后旧建议失效，避免覆盖新校对。

应用后点击“一键完成”，已有原文和中文继续复用，仅重新合成改动的语音段并导出成片；原有成片会保存到项目 `history/`。只修改句尾标点或空白的建议会被过滤，减少无意义的配音重做。

设置中的“翻译语义审校”默认自动，也可选每段审校或关闭额外审校；“优化已有译文”始终执行审校。“朗读稿等义精简”默认只在估计超时后尝试压缩口头赘词，仍检查原文数字和问句是否保留，编号、时间、角色保持不变。估算不等于实际配音长度，最终仍按真实合成音频检查对齐，无法容纳时不会截掉句尾。

此流程通用于英语/日语课程及动漫上下文，不依赖某一视频的固定术语。模型仍可能误判指代、否定或省略内容；结构检查不能证明语义完全正确，建议逐句核对关键知识点和角色关系。

## 本地模型

| 阶段 | 默认模型/运行时 |
| --- | --- |
| 识别 | faster-whisper large-v3，CUDA FP16 |
| 翻译 | Qwen3-8B Q4_K_M GGUF，llama.cpp Vulkan |
| 配音 | IndexTTS-2.5，CUDA BF16 |
| 背景分离 | HTDemucs，CUDA，30 秒流式分块 |
| 音视频 | FFmpeg / FFprobe，预览优先 NVENC |

`models/faster-whisper-large-v3-turbo` 若已准备，也可在模型设置中选择，减少识别时间和资源占用。默认使用程序管理的本地翻译进程，翻译结束后退出释放显存；也可以连接自己已有的本机兼容服务，地址只接受 localhost / 127.0.0.1 / ::1。

音频对齐默认使用 4 个 CPU 任务并行，设置中的“音频处理并行数”可选 1～8；“允许配音延后”可设 0～3 秒，设为 0 表示不接受延后。已生成的语音和已完成的对齐缓存会复用，原文、译文和字幕时间不因对齐而改写。

IndexTTS-2.5 默认使用同一模型的自适应文本批处理，最多 4 段；设置中保留双段和单段兼容模式。待生成片段按参考声音和长度分组，输出仍按原字幕编号和时间轴放回；新角色先合成一段完成参考声音预热，其余片段立即参与合批。显存余量不足时降低批量，批处理异常按 4→2→1 重试，需要分句的文本单独合成，不让一条不适合合批的文本关闭整项任务的批处理。声学解码和声码器仍逐段执行，GPU 模型仍按阶段独占使用。

“配音”页显示最近一次运行的实际批量、最大批量、新生成/复用数量、显存或文本回退原因，以及模型加载、语音生成、声学生成、声码器等耗时。模型加载与参考音准备仍需要时间，配音模型可限时保温复用；合成累计时间包含参考音处理、文本准备和文件读写。

## 项目文件

- `app/`：本地服务、任务队列、识别/翻译/配音流程与中文界面。
- `scripts/`：模型准备和独立模型工作进程。
- `projects/<项目编号>/`：视频副本、字幕、参考声音、语音缓存、导出文件、处理日志及 `project.json`。
- `models/`：模型权重；`vendor/index-tts/`：官方配音代码和独立环境。
- `runtime/`：下载缓存、llama.cpp、验收资料。
- `Data/`：用户输入素材，不作为程序依赖，不修改原文件。

配置与项目清单使用 UTF-8 无 BOM，更新采用临时文件与原子替换。运行中不允许修改当前项目，浏览器会提示未保存编辑；中断状态在下次启动时恢复为可重试状态。配音和输出按字幕、参考声音及模型信息检查，避免错误复用。

## 当前边界

- 自动语音识别不等于自动识别角色。多人对应需要人工校对；重叠对白允许保留并混音。
- 不改变人物口型；不自动擦除画面中的原字幕。
- 背景分离是估计，无法保证原背景逐样本不变；歌声、复杂音效或重叠对白可能残留或损失。有独立背景音轨时，上传自定义背景可避免模型分离误差。原音轨仍完整保留在 MKV 内。
- 英日识别、术语翻译、情绪和音色仍可能有误。保留原音轨和原文字幕便于核对。
- 原视频的 HEVC 等编码可能无法在浏览器预览；导出页会单独生成兼容 MP4，保留原画质的 MKV 可用支持多音轨的播放器观看。

## 连续试听与界面语言

配音页顶部显示模型是否加载、是否正在合成及剩余保温时间。连续调试不同句子和情绪时不必重新加载模型；首次启动、空闲到期、模型变化或切换其他 GPU 阶段后仍需加载。设置中可调整保温 0～60 分钟，默认 10 分钟；随时可手动释放显存。当前任务运行/排队时释放按钮会暂时禁用。

顶部“界面语言”可切换中英文，不修改用户字幕或项目名称，也不提交/放弃草稿。导入时支持 12 种源语言及自动检测，译制目标可选择中文、英语、日语、西班牙语或阿拉伯语。浏览器原生音视频控件的语言由浏览器决定。

## 音色库与项目角色

左侧“项目”和“音色库”是两个独立菜单。切换菜单会保留当前项目的字幕、情绪和声音草稿。

在音色库点击“新建音色”，填写名称和说明，上传 3～30 秒参考声音；推荐使用 5～15 秒清晰、少背景音的录音。可预听、修改和归档音色，已归档音色可恢复。项目内已有参考声音也可通过“存入音色库”保存成预设。

在项目的“配音与情绪”页展开“项目角色与音色”，为角色选择预设并点击“应用音色”。项目保存一份独立参考声音副本：后续修改或归档预设不会改变该项目的声音。需要采用更新后的预设时，再次应用即可。更换项目音色后，需要重新生成相关配音和成片，原有字幕不变。

音色库保存在本机 `voices/`，不随源码发布。音色预设是参考录音与名称说明，不需要为每个角色训练模型。

## 多句配音工作台

配音页可同时编辑多句中文稿、角色、情绪及强度，支持搜索台词、筛选角色和每页 20/50/100 句。勾选句子后可批量设置角色、情绪或强度；“本页全选”只选择当前筛选页，已勾选的句子跨页保留。切换项目时清空选择，避免把另一项目的句子编号误认为已选。

批量设置只更新页面草稿，点击“保存配音设置”后用于整片配音。沿用参考音时不单独指定强度。每行“细调 / 试听”可打开原速单句试听，原有情绪和模型保温机制继续生效。

## 查看处理记录

点击页面右下角“处理记录与诊断日志”，可在大面板切换运行记录和诊断日志，搜索当前显示内容，筛选错误或警告。开启“自动跟随最新”持续查看处理进度；阅读旧记录时取消勾选即可暂停刷新。

运行记录保留最近 200 条；诊断视图默认显示末尾 500 行，可增加到最多 3000 行。下载按钮会导出最近运行记录和完整进程日志。日志可能含本机路径和台词，分享前请自行检查。

## 设置布局

设置窗口分为“常用参数”和“模型与工具”两个页签。翻译、配音性能和时间对齐集中展示；模型路径按识别、翻译、配音及媒体工具分组。页签切换保留当前输入，底部保存按钮会提交两个页签的全部参数；取消则保留原配置。

## 选择译制目标语言

导入视频时分别选择原语言和译制目标语言。已有项目可在标题下方选择目标并点击“切换目标语言”；确认后，先备份旧译文、试听、字幕和输出，再清空当前译文。原文、时间轴、角色、音色及背景设置保留，随后重新翻译和配音。

IndexTTS-2.5 支持中、英、日、西、阿五种目标语言；IndexTTS-2 仅支持中英。其他源语言仍可识别并翻译到上述目标。英语、西班牙语、日语和阿拉伯语配音暂用模型原生逐句合成路径，继续复用保温模型；中文保留原有自适应批处理。

旧项目省略目标字段时按中文处理，原中文语音缓存保持兼容。其他目标的字幕为 `translated.srt` / `translated.vtt`、人声音轨为 `translated.wav`。音视频和字幕轨的语言标签随目标更新。跨语言音色克隆不保证完全消除口音，需试听确认。

## 直接录音创建音色

在“音色库 → 新建音色”中选择上传文件、话筒录制或系统录制。Windows 本机录音可以选择输入话筒或输出扬声器／耳机；系统录制只采集所选输出设备的声音，不采集画面，也不需要浏览器共享屏幕。仅按下“开始录音”才采集，最多 29 秒，停止后先试听，再保存音色。参考音仍需 3～30 秒，建议 5～15 秒清晰独白。录音结束不自动加入音色库，取消或关闭弹窗会停止本次录音。

Windows 需要允许桌面应用使用麦克风；输入无声、设备拔出、权限拒绝都会在录音区域显示错误。系统录制时应先确认所选输出设备正在播放希望使用的参考内容。设备列表的可用性不等于实际录音听感验收。其他平台保留上传文件入口。

## 小说与有声书

1. 进入“小说有声书”，新建书籍，再新建章节。每章可粘贴最多 250000 字正文。
2. 选择章节默认音色和朗读语言。正文直接转语音，不经过翻译；目前沿用 IndexTTS 对中文、英语、日语、西班牙语和阿拉伯语的语言支持。
3. 点击“自动分句”预览，也可直接保存，由程序先分句。分句按段落、句末标点和长度拆分，保留原有词句、引号、数字；长句过长时按停顿或长度继续分块，不由语言模型改写正文。
4. 在逐句朗读稿中编辑文字，或为某句覆盖音色与情绪。重新分句时，相同文字保留对应设置；修改正文并保存前会提示确认重新分句。
5. 保存后生成本章、全书或单句。进度显示排队、准备音色、加载／复用模型、生成句子和合并阶段。小说与视频共用任务队列和保温模型，避免同时重复加载两套配音模型。
6. 完成句子会即时保存。取消、关闭服务或失败后再次生成，已验证的语音缓存继续复用；修改一句只重新合成受影响内容。软件重启将未完成任务标记为中断，由用户决定继续。
7. 章节句子全部完成后，自动生成 WAV 和 MP3。所有章节完成后，可按章节顺序“合并导出全书”，选择 WAV 或 MP3。句间停顿可设 0～3 秒；全书章节之间留 1 秒停顿。整个过程保持自然语速，不为视频字幕窗口变速。

切换菜单保留章节草稿，切换章节／书籍时提示保存或放弃。已有音频显示的是已生成版本；修改正文后需要保存并重新生成。归档书籍保留正文、音色设置与音频，可在已归档列表恢复。小说目录 `audiobooks/` 和临时录音 `runtime/recordings/` 均不进入 Git。
