# Project review / 项目评估 — 2026-10-31

评估结论：视频导入、识别、翻译审校、角色音色、试听、配音合成、背景混音、视频导出和小说章节工作流已具备完整处理链路。近期缺陷集中在任务状态一致性、局部失败恢复和进度读写开销，因此本轮优先修正这些环节。评估基于当前工作区源码、既有回归和隔离验收；保留已有未提交改动，不包含远程发布或历史媒体清理。

## 本轮发现与修正

| 优先级 | 发现 | 实现与验证 |
| --- | --- | --- |
| 高 | 批量候选会保留上一轮失败项，续跑却按最近一轮的顶层模式分流；混合的识别/翻译失败可能执行错误流程 | 按每句保存的原操作类型分组。文本阶段完成后共用识别阶段，保持 GPU 交接；仅为需要翻译的句子开启文本模型。两种操作顺序均有回归测试 |
| 高 | 视频试听与整片配音只检查缓存是否存在，空 WAV、错误格式或截断 PCM 会反复被当作有效缓存 | 读取 WAV 参数并核对末帧，坏文件改名隔离后重新生成。视频和小说共用校验；权限与磁盘故障继续报错，原文件作为诊断备份保留 |
| 高 | 保存排队状态或创建缓存目录失败时，内存忙碌标记可能残留，导致无法继续提交任务 | 排队状态持久化后再预留任务；执行器拒绝时回滚预留并记录终态；目录准备纳入执行异常处理。视频、小说和模型预加载都有故障注入检查 |
| 中 | 约 150 ms 的轮询中扫描所有待合成文件，并反复读取/写入完整项目 JSON | 最多每 750 ms 扫描和发布一次，成功结束时强制刷新，完成数以保存的音频为准。每轮使用独立进度文件，启动不删除旧快照 |
| 中 | 说话人复用的回退比例只统计可复用的旧识别角色，可能忽略手动角色的大量台词；同一新分组也可能同时命中多个独立参考窗口 | 回退分母统计所有已分配角色的时间；不同参考窗口冲突时要求重新核对。相同原片参考窗口的历史重复角色仍按稳定规则处理，保持一对一对应 |

字幕工作台增加明确的重试范围：选中未完成句子时只重试这些句子；否则重试全部未完成句子。已完成候选不重复生成，原字幕继续等待明确采用。

## 验证结果与边界

- 355 项 Python 测试通过；界面语言覆盖、进度脚本和源码差异检查通过。
- 故障注入覆盖空文件、零帧、格式损坏、PCM 截断、访问错误、排队保存失败、执行器拒绝和缓存目录异常。
- 模拟 40 次、间隔 150 ms 的进度回调，20 个待处理片段的全量扫描从原代码的 40 次降为 9 次，最终 20 段完成数准确。该结果衡量轮询开销，不是 GPU 推理或整片处理的加速倍率。
- 独立浏览器项目分别恢复所选译文和剩余原声识别任务，最终两条候选、零失败；原文和已保存译文未被候选覆盖，未选中的完成项保留，控制台无错误。
- 已有真实检测时间轴只读重放仍能对应 4/4 个既有角色；没有重新运行完整视频的 Community-1 或 TTS 推理，也不将本轮测试解释为人名、翻译和相似音色识别的质量保证。

## 后续建议

1. 将项目内容与高频运行快照进一步拆分。目前整份 JSON 持久化仍会随长视频的字幕和词时间戳增长，本轮先降低无意义轮询频率。
2. 逐步集中前端的任务操作与编辑状态。目前多个模块扩展同一组全局渲染函数，后续新增页面应继续覆盖草稿、跨页选择和迟到响应场景。
3. 增加可预览的按项目缓存/备份占用统计与清理入口；保留音色、原始素材和可恢复结果，清理前明确展示范围。本轮不清理历史媒体。
4. 为不同识别、翻译和语音后端维护独立实机验收素材，分别记录质量、显存和耗时。模型质量与文件/任务处理正确性应分别验证。


## 后续建议实施

本轮已完成上述四项建议及四阶段职责重分配，详见 [workflow.md](workflow.md)。

1. **正文/快照拆分**：低频内容检查点与带摘要绑定的高频状态独立持久化；前端以正文版本决定是否读取全量字幕。原创 2300 句夹具中，30 次状态写入为 28,260 字节，正文 7,319,974 字节保持不变；不能据此推导 GPU 加速倍率。
2. **共同任务与编辑边界**：`workflow-core.js` 集中任务准备、保存与选择上下文，兼容已有页面调用。双击同任务合并，跨项目与保存期间的新输入均有回归；不需要把所有旧模块一次性重写才能使用。单句试听继续允许使用未保存草稿。
3. **存储管理**：按项目统计与预览明确范围；保护原片、当前引用、复用语音、当前校对候选和最近备份。清理前验证文件与项目版本，处理期间拒绝清理，不跟随目录联接。真实项目未执行历史媒体清理。
4. **独立模型验收**：原创英日测试文本与 Windows 系统声音生成器进入源码；统一 CLI 调用配置的识别、翻译、语音适配器，单独记录原始输出、质量观察、加载/合成时间和显存范围。实机覆盖英文识别、英日译中、两次中文配音及模型复用；日语识别因缺少独立音频夹具明确跳过。

界面职责调整为“素材与识别 → 翻译与校对 → 角色与配音 → 混音与导出”。背景音不再挤在配音页，整片重新断句回到素材页，目标语言集中在字幕页，批量操作保持在主工作台。角色准备完整时默认收起配置，让台词表优先展示；未保存台词导致预览过期时明确提示。
