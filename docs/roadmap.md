# 路线图

以下为方向，不代表发布日期或已实现功能。

## 已具备

- 四步本地工作台、上下文翻译、语义断句与逐句优化建议。
- 原速单句试听、手动情绪强度、同条件配音合批和增量缓存。
- 背景分离、页面中文字幕开关、MP4 与双音轨 MKV。

## 优先完善

- 在更多 Windows / NVIDIA 设备上验证干净安装，提供更清晰的环境诊断。
- 扩展公开可再分发的英语、日语及多角色测试素材。
- 长教程术语一致性、复杂语序与配音时长反馈。
- 改善键盘操作、窄屏编辑和失败定位体验。

## 探索方向

- 原片逐句情绪分析与情绪参考片段，保留人工覆盖与试听。
- 角色识别辅助、批量项目排队与更细的资源调度。
- 替代 TTS 后端，降低硬件要求并提供更多许可选择。
- 可复现安装包与模型准备清单。
