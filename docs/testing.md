# 测试与验收范围

## 自动回归

`uv sync --locked --group dev` 后执行：

```powershell
uv run --no-sync pytest -q
python scripts/check_repository.py
node --check app/static/app.js
node tests/check_i18n.cjs
```

FFmpeg/FFprobe 需要在 PATH。测试覆盖字幕词保留、断句、翻译匹配、编辑冲突、失败保护、取消、缓存、情绪隔离、试听、时间轴及真实 FFmpeg 混音/导出。模型使用替身，不要求 GPU、模型权重或视频素材。CI 不运行真实模型下载和推理，也不代表安装流程或听感验收通过。

## 已完成的本机验证

开发阶段在 Windows、RTX 5070 Ti 16GB、32GB 内存上验证英语单人课程流程，包含约 179 分钟成片和独立 90 秒样片。后续情绪功能在 90 秒样片验证过开心/轻度、惊讶/中度、原生合批、试听缓存和网页播放。单句回转 ASR 只辅助核对内容，不能证明情绪自然或音色相似。

这些是指定机器和素材的开发记录，不是所有设备、语言和题材的质量保证。为保护输入素材、音色与本地信息，原视频、生成音频、处理日志和私人验收目录不随仓库公开。

## 手动检查

1. 导入自己有权使用的短视频，完成识别/翻译，核对数字、否定、条件、术语和角色。
2. 编辑当前句，切换句子和页签；切换项目时确认未保存保护。
3. 使用草稿试听，确认字幕与已有成片没有被替换；保存后仅重做受影响语音。
4. 检查短配音保持原速、长句没有截尾、背景音没有不可接受的残留。
5. 播放 MP4，切换字幕、拖动进度，检查原声/中文 MKV 音轨与下载。

性能对比使用 `scripts/benchmark_tts_profiles.py --request <tts-request.json> --out <新目录>`。请求包含用户自备的 text/reference/output 等字段，格式参考代码；不要提交真实参考录音、绝对路径或测试输出。双实例测试可能需要更多显存，默认生产仍使用单实例合批。

## 模型复用与多语言补充验收

连续两句真实 IndexTTS 调试在同一进程完成；第二次请求模型加载耗时为 0，空闲到期后 GPU 锁释放。另通过页面验证连续试听和手动释放。该测试只反映指定机器与两句文本，不代表通用加速比。

新增源语言导入校验、界面词条占位符完整性、用户内容隔离，以及常驻进程的复用、取消、崩溃恢复、权重变化、参考音替换、超时和关闭测试。中英切换以浏览器检查未保存草稿保留。

`python scripts/verify_translation_quality.py --cases tests/multilingual_cases.json --out runtime/multilingual-verification` 可对法/德/西/韩示例运行实际本地模型；它验证文本语义，不等于新语种完整视频 ASR 或听感验收。

## 音色库、批量设置与日志验收

音色库 API 回归使用实际 WAV 和 FFmpeg，覆盖上传、音频范围读取、重命名、归档恢复、旧项目参考音隔离、项目忙碌拒绝和跨站请求拒绝。日志测试覆盖浏览行数限制、UTF-8 和完整进程日志下载。

页面交互在独立的 25 句验收项目上检查：只修改勾选的句子、选择跨页保留、菜单切换保留未保存台词、保存后重新读取结果，以及从角色保存音色、重新应用、归档和恢复。日志面板验证错误筛选、诊断搜索、暂停跟随和浏览器下载。验收项目与参考声音不进入源码。

## 多目标语言验收

目标语言回归覆盖旧项目默认中文、切换备份与版本冲突、跨语言缓存隔离、模型版本限制、非中文原生语言参数及真实音视频语言标签。独立 8 秒验收项目实际运行本地翻译、英/日/西/阿试听及阿拉伯语视频导出；四种试听使用同一保温模型。该验收检查生成链路和标签，不代替各语种完整视频的人工听感、口音与翻译质量评估。

Windows 语义模型加载使用显式本地张量读取，避开 Transformers/PyTorch 的存储切片崩溃；与内存映射相比，加载瞬间需要更多可用内存。实机验收期间需给模型留出足够资源。原生进程崩溃会保留退出码及故障栈，空错误不会再被当成成功。

## 导航与编辑布局验收

项目管理回归覆盖重命名、删除回收站、恢复、版本冲突、忙碌拒绝、无效名称与跨站拒绝。回收站仅标记项目元数据，原素材、历史记录和生成结果保留；回收站项目不能启动任务、读取素材或修改字幕。

浏览器使用独立的 25 句项目检查字幕对照表、跨菜单草稿、设置草稿、项目重命名及回收站恢复。配音浮层在列表中部打开和关闭，记录页面滚动位置保持一致，并检查表格容器的实际高度等于内容高度，排除内部纵向滚动。真实试听应在浮层内呈现，不触发页面底部跳转。窗口内的滚动、筛选、保存和播放器需要实际交互验证，脚本语法通过不等于布局验收。

项目不可用保护在隔离数据目录与独立本机端口验收：保留未保存的试听草稿，从另一客户端把项目移入回收站，页面应禁用试听并显示恢复按钮；恢复后草稿保持原样，仍可保存。项目缺失、项目在回收站与生成文件缺失返回不同的错误语义，避免把恢复问题误认为模型加载失败。验收不得清理仍被其他页面打开的主数据目录项目。

## 录音与小说验收

录音回归使用合成音频驱动测试提供器，覆盖设备枚举不启动采集、显式启动、重复会话拒绝、29 秒上限、取消、静音拒绝与资源释放；不自动开启用户真实话筒或录制未知系统声音。实机另检查 WASAPI 设备可枚举，实际话筒与输出设备需由用户按“开始录音”后核对听感。

小说回归覆盖小数、英文缩写、闭合引号与段落分句、无标点长文保真、混合采样率合并和停顿、真实 FFmpeg MP3／WAV 输出、逐句保存、取消续跑、缓存复用与修改失效、任务忙碌保护、版本冲突、私有文件路径和跨站请求拒绝。浏览器验收使用隔离目录及独立端口，检查录音试听保存、章节草稿和自动分句、合成阶段进度与全书导出。

本机真实 IndexTTS 验收使用两章三句中文原创短文。第一章准备模型，第二章复用同一模型，模型加载时间为 0 秒；完成章节 WAV／MP3 及全书合并。该记录不代表所有小说、音色、语种和设备的自然度或性能保证。私人参考音、生成音频及进度日志不随源码公开。
